 TaskFlow Lite

TaskFlow Lite is a lightweight, browser-based task manager built with **vanilla JavaScript**, **HTML**, and **CSS**. It allows you to manage tasks entirely on the client side with **CRUD operations** and data persistence using **localStorage**.


 Features

- **Add Tasks**: Create new tasks quickly.
- **Edit Tasks**: Update task text with a simple prompt.
- **Mark as Done/Undo**: Toggle task completion status.
- **Delete Tasks**: Remove tasks when done.
- **Persistent Storage**: Tasks are saved in localStorage and persist across page reloads.
- **Responsive Design**: Works on both desktop and mobile devices.


## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
- localStorage API
